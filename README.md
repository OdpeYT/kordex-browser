# kordex-browser
navegador basado en webkit pensado en la ligereza, privacidad y simplicidad
este navegador esta basado en Webkit, y tiene las siguientes caracteristicas principales:
-no guarda historial
-tiene un adblock incorporado
-modo volatibilidad, si esta activado no se guarda nada, y si esta desactivado si se guardan
-temas: en la seccion colores en la configuracion puedes escoger varios colores, incluyendo los de la bandera de Mexico
-marcadores: si, eso, como en cualquier otro navegador
-no hay cuentas, no hay servidores propios ni asi.
